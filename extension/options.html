Source Verifier

Configure the model that judges whether a source supports a claim.

Stored with chrome.storage.local on this machine only. It is sent directly to the provider and nowhere else — this extension has no backend.
Why the page is read in your browser. When you verify a link, the extension opens it in a hidden background tab, lets the page's own JavaScript run, and reads the rendered text using your session. That means single-page apps, login-gated pages and soft paywalls are readable here — a server-side fetcher sees an empty shell for all of them.

Because the extension does its own reading, the model only ever judges text it is handed, which is what makes the provider genuinely swappable.
